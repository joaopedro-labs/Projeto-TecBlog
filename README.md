# 📰 TecBlog — O seu Blog de Tecnologia (Versão Completa)

Portal de notícias de tecnologia desenvolvido por **João Pedro Araujo dos Santos** ([`@joaopedro-labs`](https://github.com/joaopedro-labs)) com **HTML5, CSS3 Responsivo e JavaScript**.

## ✨ Funcionalidades Finalizadas
- **Filtro Dinâmico por Categorias**: Navegação ativa entre *Home (Todas)*, *Jogos*, *Celulares*, *Informática & IA* e *Eletrônicos*.
- **Barra de Pesquisa Instantânea**: Filtra artigos em tempo real conforme o usuário digita.
- **Botão "Leia mais" Expansível**: Exibe o conteúdo completo de cada artigo sem recarregar a página.
- **Ilustrações Vetoriais (SVG) e Layout Responsivo**: Funciona perfeitamente em computadores e celulares.
